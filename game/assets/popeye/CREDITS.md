# Popeye cartoon frames

Film: *Popeye the Sailor Meets Sindbad the Sailor* (1936), Fleischer Studios, directed by Dave Fleischer. These assets are actual film stills, not AI images or newly drawn characters. Game captions are additions by this project. Original image files are unmodified. Reaction cards scale the full still; the website hero presents one still inside a circular porthole using CSS.
